# GitHub Profile Setup

1. Create/open the special repository:
   `Riwano000/Riwano000`
2. Replace its `README.md` with the supplied `README.md`.
3. Upload the entire `assets/` folder.
4. Commit the changes.
5. GitHub will render the binary portrait from:
   `assets/binary-portrait.svg`

Optional:
- Keep `assets/riwano-photo.jpg` only if you want the original photo available in the repository.
- If you don't want the original photo public, delete that file before pushing. The README only needs `binary-portrait.svg`.
